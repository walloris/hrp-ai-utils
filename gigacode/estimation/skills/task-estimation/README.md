# Простой скилл по оценке задачи
Цель скилла — оценить задачу и не уходить глубоко в локализацию проблемы, чтобы не растягивать время работы агента.

## Как работает оценка
В скилле есть ссылки на эталонные задачи и сами задачи лежат рядом в папке `examples`.
Если задачи удалить, скилл будет пытаться оценить в часах.

## Как обновить эталонную задачу
Если есть своя эталонная задача, просто дайте ссылку на джиру и хеш коммита — и скажите, обновить эталонную задачу.
