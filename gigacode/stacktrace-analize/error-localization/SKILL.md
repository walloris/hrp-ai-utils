# Error Localization

**Цель:** найти одно наиболее вероятное место причины бага. Только анализ. Код не исправлять.

## Запрещено
- Исправлять код.
- Менять файлы.
- Предлагать фиксы, рефакторинг или варианты переписывания.
- Писать план на исправление.
- Использовать других агентов или другие скилы.
- Сканировать весь проект без явной зацепки.
- Делать выводы без опоры на наблюдаемый сигнал.
- Считать сигналом: «это место просто выглядит подозрительно».
- Читать более 5 файлов суммарно за весь анализ.
- Использовать grep/glob/find для широкого поиска по проекту.

## Быстрый путь — проверь первым

Если во входных данных есть **stack trace** или **сообщение об ошибке с именем класса/метода** —
перейди сразу к разделу «Финальная гипотеза». Шаги 2–4 пропустить.
Файлы читать только если имя класса/метода не однозначно идентифицирует место.

## Как анализировать

**1. Зафикси симптом (1–3 строки)**
- что ожидалось;
- что произошло фактически;
- какое влияние у бага.

**2. Найди стартовую точку (в порядке приоритета)**
- stack trace → это уже стартовая точка, файлы не открывать
- сообщение об ошибке с именем класса → использовать напрямую
- только описание симптома → найти ближайший модуль, не более 2 file reads

**3. Исследуй только ближайшую цепочку вызовов**
- входные данные, изменения состояния, побочные эффекты, граничные условия
- не уходи глубже 3 уровней вызовов без нового сигнала

**4. На каждом шаге реши: это источник или подняться на 1 уровень выше?**

**5. Остановись, когда:**
- найден один сильный кандидат
- новых зацепок нет
- данных недостаточно для надёжного вывода
- прочитано 5 файлов — выдай лучший вывод на основе имеющегося

## Правила для ответа
- Нет конкретного сигнала → не называй место вероятной причиной.
- Не смешивай симптом и гипотезу.
- Не пиши исправление, даже если оно очевидно.
- Если уверенность низкая — честно укажи это.

## Формат вывода

```markdown
---
**🏁 РЕЗУЛЬТАТ АНАЛИЗА**

- **Проблема:** [что должно было произойти], но вместо этого [что произошло фактически]; влияние: [что это ломает]

- **Наиболее вероятное место:**
  - Файл: `путь/к/файлу` [строки N–M]
  - `ClassName` — `functionName()` — [краткая причина]
  - Сигнал: [конкретный лог / stack trace / условие / входные данные]
  - Почему это похоже на источник: [1–2 коротких предложения]

- **Уверенность:** высокая / средняя / низкая
---
```
