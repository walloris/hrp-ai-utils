# Skill: OpenAPI Description Completeness Checker and Fixer

## Назначение
Проверяет файл OpenAPI спецификации на наличие пропущенных описаний в параметрах (`parameters`) и свойствах (`properties`) схем, генерирует предложения по исправлению.

## Правила проверки

### 1. Проверка параметров
Для каждой конечной точки (`endpoint`):
- Проверяет, что каждый параметр имеет непустой `description`
- Выявляет параметры без ключа `description`
- Выявляет параметры с пустым `description: ""`

### 2. Проверка свойств схем
Для каждой схемы в `components/schemas`:
- Рекурсивно проверяет все свойства
- Обеспечивает наличие непустого `description` для каждого свойства
- Обрабатывает вложенные объекты и элементы массивов

## Выходной формат

```
Found X issues:
================================================================================

PARAMETERS WITHOUT DESCRIPTIONS:
  Missing: Y
  Empty: Z

  Line N: paths...endpoint.parameters[M] - parameterName

PROPERTIES WITHOUT DESCRIPTIONS:
  Missing: A
  Empty: B

  Line N: components.schemas.SchemaName.properties.propertyName
```

## Стратегия исправления

1. Анализирует структуру файла и находит точное место для добавления
2. Генерирует русское описание на основе названия свойства
3. Предоставляет точную строку для вставки с правильной отступкой
4. Сохраняет существующие описания без изменений

## Примеры описаний (автоматическое формирование)

| Имя свойства | Описание |
|--------------|----------|
| `id` | Идентификатор |
| `name` | Название |
| `isActive` | Флаг активности |
| `createdAt` | Дата и время создания |
| `createdBy` | Автор создания |

## Особенности

- Проверяет свойства, параметры и вложенные объекты
- Генерирует описания автоматически на основе названий
- Требует ручного применения исправлений через `edit` с точным контекстом
- Сохраняет все существующие описания без изменений
- Не вызывает специализированных агентов
