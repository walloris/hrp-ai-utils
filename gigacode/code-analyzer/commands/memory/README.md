# Memory commands

## Описание
Создаёт или обновляет память проекта в `.gigacode/memory/`.
Учит гигакоде вычитывать память при работе с проектом.
После прохождения онбординга создадутся все необходимы файлы и больше нечего делать не нужно.

## Установка
Положить папку `memory` целиком в папку `~/.gigacode/commands/`
```
~/.gigacode/commands/
├── memory/
│   ├── init.md
│   ├── repair.md
│   └── update.md
```

## Команды
- init - изучить новый проект
- update - обновить проектный контекст
- repair - восстановить `.gigacode/settings.json` или memory-файлы
