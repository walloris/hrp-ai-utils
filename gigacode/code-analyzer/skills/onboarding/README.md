# Onboarding Skill

Создаёт или обновляет память проекта в `.gigacode/memory/`.
Учит гигакоде вычитывать память при работе с проектом.
После прохождения онбординга создадутся все необходимы файлы и больше нечего делать не нужно.

Используй, чтобы:
- изучить новый проект
- обновить проектный контекст
- восстановить `.gigacode/settings.json` или memory-файлы

Что делает:
- анализирует структуру проекта, стек, entrypoints, тесты и CI
- сохраняет память в `.gigacode/memory/`

Примеры:
- `пройди онбординг`
- `изучи проект и создай память`
- `обнови контекст проекта`
