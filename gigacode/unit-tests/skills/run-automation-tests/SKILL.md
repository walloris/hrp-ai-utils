# run-automation-tests

Этот навык запускает все автотесты в Maven-проекте и проверяет результат выполнения.

## Overview

Навык выполняет следующие действия:
1. Собирает проект и запускает все тесты через Maven
2. Проверяет результат выполнения
3. Возвращает отчёт о результатах

**Важно:** Этот навык универсален и может работать с любым Maven-проектом.

## Usage

```
skill: "run-automation-tests"
```

Навык спросит:
1. **Путь к проекту** — путь к директории с Maven-проектом

## Критерии успешного завершения

1. **Тесты собрались и запустились** — команда `mvn test` выполнилась без ошибок сборки
2. **Тесты прошли** — все тесты завершились с результатом `PASSED`, нет проваленных (`FAILED`) или ошибок (`ERROR`)

## Формат вывода

### Успешное выполнение:
```
=== Запуск автотестов ===
Project: /path/to/project (ProjectName)
Time: ...

✅ Все тесты успешно прошли

Результаты:
- Всего тестов: 42
- Прошло: 42
- Провалено: 0
- Ошибок: 0
- Пропущено: 0
- Время выполнения: 15.3s
```

### Неуспешное выполнение:
```
❌ Тесты завершились с ошибками

Результаты:
- Всего тестов: 42
- Прошло: 38
- Провалено: 3
- Ошибок: 1
- Пропущено: 0

Ошибки:
1. SomeClassTest.testMethod1 - AssertionError: expected: ...
2. ...
```

## Как работает

1. Запускает `mvn clean test` в указанной директории проекта
2. Ищет Maven в GIGA IDE (поддержка нескольких версий)
3. Парсит output Maven на предмет результатов тестов
4. Проверяет:
   - Нет ли ошибок компиляции/сборки
   - `Errors: 0` и `Failures: 0` в результатах тестов

- **GIGA IDE PRO 2024.5** — альтернативная версия
- **GIGA IDE BACK 2024.2 EAP** — альтернативная версия

## Обработка ошибок

- **Ошибка сборки Maven** — фиксируется как провал с описанием проблемы
- **Провал тестов** — фиксируется с перечислением конкретных тестов
- **Таймаут выполнения** — если выполнение занимает более 10 минут
