# jacoco-coverage-analyzer

Этот навык анализирует отчёт о покрытии кода JaCoCo и выдаёт топ-10 классов с наименьшим покрытием.

## Overview

Навык выполняет следующие действия:
1. Ищет отчёт JaCoCo в указанном Maven-проекте
2. Парсит XML-отчёт и извлекает данные о покрытии по классам
3. Сортирует классы по проценту покрытия (возрастание)
4. Возвращает топ-10 классов с наименьшим покрытием

**Важно:** Этот навык универсален и может работать с любым Maven-проектом, где сгенерирован отчёт JaCoCo.

## Usage

```
skill: "jacoco-coverage-analyzer"
```

Навык спросит:
1. **Путь к проекту** — абсолютный путь к директории с Maven-проектом
2. **Имя проекта** — для удобства отображения в отчёте (опционально)

## Формат вывода

```
=== Анализ покрытия кода (JaCoCo) ===
Project: /path/to/project (ProjectName)

ТОП-10 КЛАССОВ С НАИМЕНЬШИМ ПОКРЫТИЕМ:
 1.  29.73% | RequestProcessorService
 2.  33.33% | BearerTokenInterceptor
 3.  37.50% | AiAgentApplication
 ...
```

## Как работает

1. Ищет файл `jacoco.xml` в `target/site/jacoco/` проекта
2. Парсит XML с помощью Python
3. Извлекает покрытие по каждому классу (по счетчику INSTRUCTION)
4. Сортирует и выводит топ-10 с наименьшим покрытием

## Поддерживаемые окружения

- **GIGA IDE PRO 2025.1** — основная версия
- **GIGA IDE PRO 2024.5** — альтернативная версия
- **macOS/Linux** — с Python 3.x

## Обработка ошибок

- **Отчёт не найден** — если `jacoco.xml` отсутствует, предлагает сгенерировать отчёт
- **Ошибки парсинга** — фиксируется ошибка парсинга XML
- **Нет данных** — если в проекте нет классов с покрытием < 100%
