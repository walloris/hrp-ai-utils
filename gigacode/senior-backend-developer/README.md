## Команды сборки (Критически важно!)

### OFFLINE режим (Рекомендуется - предотвращает блокировку учётной записи)

**Для всех обычных сборок (после первоначальной настройки):**
```bash
./mvnw -Dmaven.wagon.http.ssl.insecure=true -Dmaven.wagon.http.ssl.allowall=true -Dmaven.wagon.http.ssl.ignore.validity.dates=true clean install -o
```

**Для запуска тестов:**
```bash
./mvnw -Dmaven.wagon.http.ssl.insecure=true -Dmaven.wagon.http.ssl.allowall=true -Dmaven.wagon.http.ssl.ignore.validity.dates=true test -o
```

### Первоначальная сборка (Зависимости отсутствуют)

**Скачать зависимости один раз:**
```bash
./mvnw -Dmaven.wagon.http.ssl.insecure=true -Dmaven.wagon.http.ssl.allowall=true -Dmaven.wagon.http.ssl.ignore.validity.dates=true -U -DskipTests clean install
```

**Затем переключитесь на OFFLINE режим для всех последующих сборок.**

---

## Объяснение флагов SSL

| Флаг | Назначение |
|------|-----------|
| `-Dmaven.wagon.http.ssl.insecure=true` | Отключить проверку SSL-сертификатов |
| `-Dmaven.wagon.http.ssl.allowall=true` | Разрешить все SSL-сертификаты |
| `-Dmaven.wagon.http.ssl.ignore.validity.dates=true` | Игнорировать срок действия сертификатов |
| `-U` | **Принудительное обновление - ИЗБЕГАЙТЕ! Вызывает блокировку учётной записи** |
| `-o` | **Оффлайн режим - ИСПОЛЬЗУЙТЕ! Нет доступа к Nexus** |

## Важные правила

- ✅ **ВСЕГДА** запускайте проверку сборки после любых изменений кода
- ✅ **ВСЕГДА** убедитесь в `BUILD SUCCESS` перед завершением задачи
- ✅ **ВСЕГДА** исправляйте падающие тесты - не пропускайте их
- ✅ **ВСЕГДА** следуйте существующим паттернам кода и соглашениям
- ✅ Используйте флаг `-o` для оффлайн сборок для предотвращения доступа к Nexus
- ❌ **НЕ КОМИТЬТЕ** код без успешной проверки сборки
- ❌ **НЕ ВНОСИТЕ** нарушения стиля кода
- ❌ **НЕ ЗАБЫВАЙТЕ** запускать тесты после изменений
- ❌ **НЕ ИСПОЛЬЗУЙТЕ** флаг `-U` в обычных сборках (вызывает блокировку учётной записи)

## Рабочий процесс тестирования

### Запуск конкретного падающего теста
```bash
./mvnw -Dmaven.wagon.http.ssl.insecure=true -Dmaven.wagon.http.ssl.allowall=true -Dmaven.wagon.http.ssl.ignore.validity.dates=true test -Dtest=LandingServiceTest#testGetAllByRealmNameFilter -o
```

### Запуск всех тестов в классе
```bash
./mvnw -Dmaven.wagon.http.ssl.insecure=true -Dmaven.wagon.http.ssl.allowall=true -Dmaven.wagon.http.ssl.ignore.validity.dates=true test -Dtest=LandingServiceTest -o
```

### Запуск всех тестов в проекте
```bash
./mvnw -Dmaven.wagon.http.ssl.insecure=true -Dmaven.wagon.http.ssl.allowall=true -Dmaven.wagon.http.ssl.ignore.validity.dates=true clean test -o
```

**Проверка результатов тестов:**
- Все тесты должны пройти с `BUILD SUCCESS`
- Нет падающих тестов или ошибок
- Покрытие кода тестами не должно значительно уменьшаться

## Типичные ошибки сборки

### Ошибки компиляции
- Исправьте синтаксические ошибки
- Обновите импорты
- Разрешите отсутствующие зависимости

### Падающие тесты
- Исправьте падающие тесты
- Обновите ассерты тестов
- Проверьте тестовые данные

### Конфликты зависимостей
- Проверьте зависимости POM
- Разрешите конфликты версий
- Используйте `mvn dependency:tree` для анализа

---

## Ключевые моменты

1. **Всегда используйте флаг `-o`** для оффлайн сборок, чтобы предотвратить блокировку учётной записи
2. **Используйте флаг `-U` только один раз** для скачивания зависимостей при первом запуске
3. **Проверка сборки обязательна** перед любым交付 кода
4. **Все тесты должны пройти** - пропуск не допускается
5. **Следуйте существующим паттернам** - поддерживайте согласованность стиля проекта
