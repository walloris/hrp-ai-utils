# Наработки по GigaCode CLI

Каталог промптов/скилов/субагентов для GigaCode CLI в разрезе этапов ПП


## Структура репозитория

```
<этап ПП>
└──skills/                      #  реестр скилов для конкретного ПП
    ├── README.md
    └── <skill-name>/           # каждый скилл — отдельная папка
        ├── SKILL.md            # инструкция для агента
        ├── metadata.md         # метаинформация
        └── scripts/ 
└──tasks/                       #  реестр субагентов для конкретного ПП
    ├── README.md
    └── <task-name>/            # каждый субагент — отдельная папка
        ├── SKILL.md                # инструкция для агента
        ├── metadata.md             # метаинформация
        └── scripts/ 


В каждом папке для скилов/субагентов можно делать вложенную папку "именную", где складываем свои наработки
по каждому из скилов в рамках ПП - затем обсуждаем и думаем что выносим как универсальное решение
