# code-writer

Скилл для реализации задач в коде. Работает по описанию, техническому запросу или номеру Jira-задачи.

### Лучше использовать после прохождения onboarding другим скиллом
> Путь к скиллу Onboarding **code-analyzer/skills/onboarding/SKILL.md**

## Использование

```
реализуй задачу PROJECT-123
```
```
добавь эндпоинт для получения списка пользователей с фильтрацией по статусу
```

## Процесс

1. Разбирает задачу и фиксирует требования
2. Читает память проекта из `.gigacode/memory/`
3. Изучает релевантный код
4. Пишет минимальное решение в стиле проекта
5. Проверяет сборку, тесты и форматирование

Скилл опирается на `.gigacode/memory/` — память о проекте, его соглашениях и паттернах.
Без неё агент изучает проект с нуля при каждой задаче.

Перед первым использованием запусти онбординг:

```
проведи онбординг проекта
```

После этого `code-writer` будет знать структуру проекта, соглашения по коду и когда читать reference-файлы — без лишних вопросов и исследований.
